## 🚀 How to Run

### Step 1: Clone the Repository
Open your terminal and run:
git clone https://github.com/Gracyclub/day-7-mata-python-sketch.git
cd day-7-mata-python-sketch

### Step 2: Install Dependencies
Install required libraries using pip:
pip install opencv-python numpy

### Step 3: Project Directory Setup
Ensure the script and image are placed together:
day-7-mata-python-sketch/
├── day7_kaalratri.py
└── kaalratri.jpg

### Step 4: Run the Script
Execute the script using:
python day7_kaalratri.py

### Step 5: Controls
- Press 'q' on the keyboard to exit the animation.
